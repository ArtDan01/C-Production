  Для запоминания:

    0000    ... 
x   1016    10
            ...
p   2056    1016    
            ...
pp  8000    2056
            ...
Так задано по условие распределение элементовв памяти по условию выше
Х хранит в ячейке значение, P это указатель на Х, он указывает на номер ячейки в которой лежит значение переменной Х, РР это указатель на указатель на 
переменную Х, то есть он держит в ячейке НОМЕР ЯЧЕЙКИ, которая хранит НОМЕР ячейки, в которой лежит значение переменной  Х.
Нагромождение ***** просто задает последовательность сколько у тебя указателей на указатель вот и все
& - это операция взятия адреса переменной, любой переменной, можно взять адрес у переменной int **************** ptr;
* - операция разыменовывания, она находит какое значение лежит в ячейке по адресу, который ты разыменовывешь


Правильное решение:
&p == 2056;
&pp == 8000;
pp == 2056;
*pp == 1016;
**pp == 10;
pp[0] == 1016;
pp[0][0] == 10;
*pp[0] == 10;


Массивы передаются в функцию 2-мя способами:
    1. Передать указатель на первый элемент и количество элементов
        void count (int* array, int size)
        /* int arr[5] = {0};
        count(arr, 5);
        */
    2. Передать указатель на первый элемент и указатель на следующий за последним
        void count(int* array, int* limit)
        /* int arr[5] = {0};
        count(arr, arr + 5);
        */
Передавая в функцию просто arr, ты все равно передаешь УКАЗАТЕЛЬ НА ПЕРВЫЙ ЭЛЕМЕНТ
